# 🎬 Kiro Sonnet Player

**Status:** ✅ Production Ready | 🚀 Auto-Deploy Enabled

Ultra-optimized Android video player with hardware acceleration and zero-lag performance.

## 🚀 Quick Links

- **Repository:** https://github.com/BOSSincrypto/kiro-sonnet-player
- **Latest Release:** [Download APK](https://github.com/BOSSincrypto/kiro-sonnet-player/releases/latest)
- **Issues:** [Report Bug](https://github.com/BOSSincrypto/kiro-sonnet-player/issues)

## ✨ Features

- ⚡ **Zero-lag playback** with hardware acceleration
- 🎮 **Intuitive gesture controls** (swipe to seek, volume, brightness)
- 🖼️ **Picture-in-Picture mode**
- ⚙️ **Variable playback speed** (0.25x - 3.0x)
- 🔖 **Bookmarks & timestamps**
- 📱 **Material Design 3 dark theme**
- 🎯 **Supports MP4, MKV, AVI, WebM**

- Android 14+ (API 34)

## 🎮 Gesture Controls

```
Single Tap         → Show/Hide controls
Double Tap         → Play/Pause
Swipe Left/Right   → Seek ±10 seconds
Swipe Up/Down (L)  → Brightness control
Swipe Up/Down (R)  → Volume control
```

## 🛠️ Tech Stack

- **Kotlin** 2.0.20
- **ExoPlayer (Media3)** 1.4.1
- **Jetpack Compose** + Material3
- **Hilt DI** - Dependency Injection
- **Clean Architecture** (MVVM)

## 🔧 Performance Optimizations

- ✅ Hardware-accelerated decoding
- ✅ 50MB smart buffering
- ✅ 200MB network cache
- ✅ R8 full mode optimization
- ✅ ABI splits for smaller APKs
